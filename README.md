## Preview
Open `index.html` in a browser, or use VS Code Live Server.

## Publish with GitHub Pages
1. Create a public repository named `wedding-invitation`.
2. Upload the contents of this folder to the repository root.
3. Open repository Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch, select `main` and `/(root)`, then Save.
5. GitHub will provide a URL like `https://YOUR-USERNAME.github.io/wedding-invitation/`.

## Custom domain routing
To publish at `varchasvi.net/wedding-invitation/` while retaining an existing Namecheap-hosted main site, upload the files into `public_html/wedding-invitation/` on that hosting account. GitHub Pages custom-domain configuration does not independently map a project site to an arbitrary path on a separately hosted root domain.

Alternatively, host on GitHub Pages at a subdomain such as `invite.varchasvi.net` by configuring the subdomain DNS CNAME to `YOUR-USERNAME.github.io` and adding that custom domain in GitHub Pages settings.

Do not change the root domain's DNS records unless you intend to move the main website too.
